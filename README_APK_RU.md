# ULTRA CHAT Android
Исходники Android WebView-приложения. GitHub Actions автоматически собирает debug APK при push в main или вручную через Actions.

После успешной сборки скачайте артефакт ULTRA-CHAT-debug-APK. Это тестовая debug-сборка. Для Google Play потребуется release-подпись.

AI-чат подключается к OpenAI-compatible API, например llama.cpp server. Генерация фото/видео требует отдельного backend.
